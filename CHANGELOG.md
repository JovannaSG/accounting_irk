# История изменений

Формат — Keep a Changelog (https://keepachangelog.com/ru/1.1.0/).

## [1.0.0] — 2026-08-23

Первый релиз прототипа «ИИ-Аудитор 1С».

### Добавлено

**Проверки по ТЗ (§4)**
- 4.1 Красное сальдо — отрицательные остатки на активных счетах и дебетовые
  на пассивных; период возникновения находки.
- 4.2 Развернутое сальдо — одновременные Д и К остатки по одной аналитике.
- 4.3 Незакрытое сальдо на конец месяца + зависшее сальдо между периодами +
  опциональный контроль групп счетов (авансы, РБП, товары, денежные средства,
  кредиты).
- 4.4 Остатки на служебном счете 000.
- 4.5 Незакрытые расчеты с контрагентами — по реестру документов (с FIFO-возрастом
  долга и ожидаемым закрывающим документом) или эвристикой по ОСВ;
  расхождение документов и остатков ОСВ.
- Каждая проверка включается/отключается в боковой панели
  (`checks={"red_balance", ...}`).

**ML-проверки (statistical, unsupervised)**
- Нетипичные суммы операций по истории контрагента (медиана + MAD,
  настраиваемые пороги).
- Резкие скачки оборотов между периодами (рост и падение).
- Возможные дубли контрагентов — нечеткий поиск (rapidfuzz).

**NLP-проверка назначений платежей (115-ФЗ)**
- Rule-based сканирование колонки «Назначение» реестра документов:
  обнал, нетиповые переводы/комиссии, пожертвования между юрлицами,
  займы без ссылки на договор, расплывчатые основания без документа,
  наличная форма расчетов.
- Категория риска в комментарии находки («[Обнал] …»); тихий пропуск
  при отсутствии колонки; поддержка пользовательских ключевых слов.

**Отчеты (ТЗ §6)**
- Сводный отчет: статус, число флагов, суммы по видам проверок,
  рекомендации к каждой находке (ТЗ п.13).
- Детальный отчет с фильтрацией по проверке, счету и контрагенту.
- Экспорт в Excel (цветовая индикация красный/желтый, лист «Об отчете»)
  и PDF (fpdf2 + DejaVu, печатная форма с реквизитами).

**Данные и интеграции**
- Загрузка ОСВ из файлов: CSV / XLS / XLSX / HTML (реальные выгрузки 1С,
  многострочный заголовок, субконто с наследованием счета, БУ/НУ-ведомости);
  MXL не поддерживается.
- Опциональный реестр документов (CSV) для проверки 4.5 и NLP.
- Подключение к 1С:Фреш по OData (`core/api_client.py`): ОСВ напрямую из базы,
  помесячная загрузка, drill-down до аналитики счета.
- Тестовые данные для демонстрации без файлов.

**Интерфейс и инфраструктура**
- Streamlit UI: мастер-дашборд по базам, детализация по счетам (drill-down),
  история аудитов в SQLite со сравнением прогонов (исправлено/новое/осталось),
  аудит по выбранным счетам/контрагенту.
- Docker-развертывание (Dockerfile + docker-compose.yml, healthcheck).
- CI на GitHub Actions: ruff + pytest при push/PR.
- 173 автотеста (ядро, загрузчики, OData-клиент, ML/NLP, отчеты, UI).

### Известные ограничения
- Формат MXL не поддерживается (сохраните выгрузку как Excel/HTML).
- Обычная ОСВ не содержит аналитику — проверки 4.2/4.5 полноценно работают
  с выгрузкой с субконто или реестром документов.
- Аутентификация не встроена — ограничивайте доступ на уровне reverse proxy.
